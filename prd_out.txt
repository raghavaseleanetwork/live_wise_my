1. Product Overview & Vision

1.1 What is LifeWise?
LifeWise is a Family Operating System — a single mobile application that allows one family to manage every member's health, finances, reminders, documents, and daily routines from one place. It is NOT just a reminder app or a medicine tracker. It is the command center for your family.

Core Positioning
LifeWise = One app to manage the entire family. From Papa's medicine to electricity bills, from Mummy's doctor appointments to children's study schedules — everything in one place, accessible by the whole family.

5.5 Connected Member / Caregiver System
This is the core of the shared family system. A family member's data can be managed by one or more other family members (caregivers).

How Connection Works
During Step 3 (or in Member Settings), user sees: 'Who should manage or receive alerts for [Name]?'
Shows list of all other family members in the system
User selects one or more caregivers
Selected caregivers are saved as connected_users
Every reminder for that member is sent to both: the member AND all connected caregivers
Any connected caregiver can mark reminder as Done/Taken
When one caregiver marks Done, it syncs instantly to all others (via WebSocket)

6.2 Reminder Lifecycle
Reminder created (manual or via module setup)
Stored in DB with status: PENDING
At scheduled time: FCM push notification sent to member + caregivers
Notification has action buttons: Mark Done / Snooze / Skip
If user taps Mark Done: status → COMPLETED, all caregivers sync
If user taps Snooze: status stays PENDING, new notification scheduled in X minutes
If no action in 30 minutes: status → MISSED, alert sent to caregivers
Missed reminders shown in red on Reminders tab and Home screen
End of day: daily summary push notification — '3 reminders missed today'

9. AI Features — Voice, Camera, WiseAI

9.1 Voice Reminder (Microphone Icon — Home Screen)
Tap the mic icon on Home screen. Full-screen modal with waveform animation appears.

User speaks: 'Papa ko kal subah 8 baje medicine leni hai'
Audio sent to OpenAI Whisper API for transcription
Transcription sent to LLM (Claude/GPT) for entity extraction:
Member: Papa
Action: Medicine reminder
Time: 8 AM tomorrow
App shows: 'Creating reminder for Papa — Medicine — Tomorrow 8:00 AM'
Confirm → reminder saved
User can edit before saving

9.2 Bill Scan (Camera Icon — Home Screen)
Tap camera icon — opens camera with document crop overlay
User captures bill image
Image sent to Google ML Kit OCR
Extracted text analyzed: bill name, amount, due date
Form pre-filled with extracted data
User selects which family member this bill belongs to
User confirms and saves — bill added to Bills module

9.3 WiseAI Chat (AI Chat Icon — Home Screen)
Full-screen chat interface powered by Claude API.

'How much have we spent on food this month?' → Expense breakdown
'Mummy ki next doctor appointment kab hai?' → Appointment details
'Show me Papa's BP readings for last month' → Health data summary
'Add a reminder to call Dadi every Sunday at 7 PM' → Creates reminder
'Which of our subscriptions are expiring soon?' → Subscription summary

WiseAI Implementation
WiseAI has access to the current user's family data via a secure context injection. The system prompt includes family member names, modules, and relevant data. Claude API (claude-sonnet-4-20250514) processes queries and returns natural language responses. Sensitive data like document images are never sent to the AI.

Every user has an FCM token stored in DB on login

Notification payloads include: reminder_id, member_id, action_type

10.3 WebSocket Real-Time Sync (Socket.io)
Used for instant sync when a caregiver takes action on a shared reminder.
Room: Each family group has a socket room (family_group_id)
On Mark Done: Server emits REMINDER_UPDATED event to all room members
All clients update local state immediately
Fallback: If WebSocket disconnected, poll API every 30 seconds

10.4 iOS-Specific Implementation
Use react-native-permissions for notification permission
Background notifications: background_fetch + silent push
UNUserNotificationCenter for local notification scheduling
Critical alerts (SOS): requires Apple entitlement
Notification categories with action buttons registered at app launch

10.5 Android-Specific Implementation
Foreground Service for medicine reminders — runs even when app killed
AlarmManager (exact alarms) — requires SCHEDULE_EXACT_ALARM permission
Battery optimization: prompt user to whitelist app in battery settings
Notification channels — create separate channels per module for granular control

13. Edge Cases & Error States

13.1 Offline Behaviour
App caches last-fetched data in AsyncStorage / MMKV
User can view existing reminders offline
Actions taken offline (mark done) are queued in local state
On reconnection: sync queue flushes to server
Show 'You are offline' banner when no connection detected

13.2 Simultaneous Caregiver Actions
If two caregivers tap 'Mark Done' at same time: first-write wins
Second write is idempotent — no error, just status already COMPLETED
Both users see COMPLETED state after WebSocket sync

13.3 Reminder Scheduling Edge Cases
Medicine time in past when adding → start from next occurrence
Monthly reminder on 31st for months with 30 days → use last day of month
Reminder for member who has no caregivers → notify member only
FCM token expired → re-fetch on next app open, skip notification
App uninstalled by caregiver → remove FCM token, remove from notify list

13.4 Data Deletion & Privacy
Delete member → soft delete (is_active: false), data retained 30 days
Hard delete after 30 days or on explicit user request
Caregiver removed → immediately stop sending them notifications
User account deletion → delete all family data, members, reminders
Document deletion → remove from S3 + DB
